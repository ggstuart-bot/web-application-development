In this unit we will write JavaScript programmes that run in the terminal with Deno.
We will meet the books data our app will use later, and practise the everyday language features the server code relies on.

<!--more-->

> JavaScript was developed for the browser, and it is still the language of the web there.
> The same language now runs on the server too, which is how we will use it in this module.
> If you are interested in using JavaScript in the browser, you can choose the optional *advanced web development* module in the final year.

We will not build a web server in this unit.
That starts in the next one.
